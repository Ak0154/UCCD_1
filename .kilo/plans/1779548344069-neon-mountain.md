### Step 2: Rewrite `services/translation_service.py`

Delete the existing Groq-based `translate()` function and the module-level `client`. Replace with:

**Class: `TranslationStage` (Enum)**
- `INBOUND = "inbound"` — user ticket text coming in (auto-detect → en-IN)
- `PREVIEW = "preview"` — `/translate-preview` API endpoint
- `DRAFT = "draft"` — agent reply going out to user (en-IN → user's language)
- `REPORT = "report"` — formal report output (en-IN → target)

**`_route(stage, target_lang)` — deterministic routing (no API calls, pure if/else):**

| Stage | Model | Mode | Source Lang | Target Lang |
|---|---|---|---|---|
| INBOUND | mayura:v1 | modern-colloquial | auto | en-IN |
| PREVIEW | mayura:v1 | modern-colloquial | auto | target_lang or en-IN |
| DRAFT | sarvam-translate:v1 | formal | en-IN | target_lang |
| REPORT | sarvam-translate:v1 | formal | en-IN | target_lang |

**`_call_sarvam(payload)` — single API call:**
- POST to `/translate` with JSON body
- On 5xx: raise exception for retry
- On 4xx: raise exception (no retry)
- On success: return parsed response dict

**`_call_with_fallback(primary_payload, fallback_payload)` — retry logic:**
- Try primary → if success, return
- If primary fails, try fallback (mayura:v1 with formal mode)
- If both fail, return `{"translated_text": original, "detected_language": None, "translation_status": "failed"}`
- Fallback only applies to DRAFT/REPORT stages (OUTBOUND)

**Error handling:**
1. Token missing → log warning, status `"skipped"`, return original text
2. 4xx → status `"failed"`, return original text
3. 5xx → retry once after 1s, then status `"failed"`, return original text

import asyncio
from services.translation_service import SarvamTranslationService, TranslationStage

def run_translation(state: ComplaintState) -> dict:
    svc = SarvamTranslationService()
    result = asyncio.run(svc.translate(
        text=state["raw_text"],
        stage=TranslationStage.INBOUND
    ))
    return {
        "translated_text": result["translated_text"],
        "detected_language": result["detected_language"],
        "translation_status": result["translation_status"]

@router.get("/translate-preview")
async def translate_preview(
    text: str = Query(...),
    target_lang: str = Query(...)
):
    cleaned_lang = target_lang.split("-")[0].lower()
    if cleaned_lang == "en":
        return {"translated_text": text}

    svc = SarvamTranslationService()
    result = await svc.translate(
        text=text,
        stage=TranslationStage.PREVIEW,
        target_lang=target_lang
    )
    return result

## Routing Matrix Summary

| Scenario | Model | Mode | Source → Target |
|---|---|---|---|
| Inbound ticket text | mayura:v1 | modern-colloquial | auto → en-IN |
| Translate-preview API | mayura:v1 | modern-colloquial | auto → query param |
| Draft reply to user | sarvam-translate:v1 → fallback mayura:v1 | formal | en-IN → detected_lang |
| Report generation | sarvam-translate:v1 → fallback mayura:v1 | formal | en-IN → target_lang |

---

## Error Handling Matrix

| Condition | Behavior |
|---|---|
| `SARVAM_ACCESS_TOKEN` missing | Log warning, status `"skipped"`, return original text |
| Sarvam 4xx | Log error, status `"failed"`, return original text |
| Sarvam 5xx | Retry once after 1s, then status `"failed"`, return original text |
| Both primary + fallback fail | Status `"failed"`, return original text |
| Pipeline node fails | Never stop pipeline — translation failure is non-blocking |
