# OmniResol Landing Page

React + Vite + Tailwind + Framer Motion implementation of the OmniResol marketing landing page (see `../landingpage.md`).

## Run locally

```bash
cd frontend
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173). The API at `http://localhost:8888` already allows this origin via CORS.

## Build

```bash
npm run build
npm run preview
```
